# MobyConnex — ระบบดีไซน์ (Design System)

เว็บไซต์ระบบดีไซน์และคอมโพเนนต์กลางของ **MobyConnex** ใช้เป็นมาตรฐานงานออกแบบสำหรับทุกผลิตภัณฑ์และงานลูกค้า
พร้อมหน้าเว็บบริการสำหรับลูกค้า (showcase) อยู่ในโปรเจกต์เดียวกัน

> โครงสร้างอ้างอิงจากระบบดีไซน์ของพรรคประชาชน (components.pplethai.org) — sidebar นำทาง, Foundations → Components →
> Patterns → Guidelines, เดโมจริงพร้อมโค้ดคัดลอกได้, โหมดสว่าง/มืด, ค้นหาด้วย ⌘K

## เทคโนโลยี

- **React + TypeScript + Vite** — build เป็นไฟล์ static
- **Tailwind CSS** — สีทั้งหมดอ้าง CSS variable ใน `src/styles/tokens.css`
- **Radix UI** primitives + `class-variance-authority`, `lucide-react`, `sonner`, `cmdk`, `date-fns`
- **ฟอนต์**: Kanit (หัวข้อ) + IBM Plex Sans Thai Looped (เนื้อความ) ฝังในเว็บเองผ่าน `@fontsource`
- **Docker + nginx** สำหรับ deploy, หน้าเว็บให้บริการผ่าน Caddy (HTTPS อัตโนมัติ)

## เริ่มพัฒนา

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # build ไปที่ dist/
npm run preview    # ตรวจ build ก่อน deploy
```

## Deploy (Docker)

```bash
docker compose up -d --build     # ให้บริการที่ 127.0.0.1:3110
```

Caddy ทำหน้าที่หน้าเว็บ + HTTPS:

```
design.bizxai.cloud {
    encode gzip zstd
    reverse_proxy 127.0.0.1:3110
}
```

## ตรวจรับก่อนส่งงาน (สำคัญ)

```bash
bash scripts/verify-all.sh [base_url]
```

สคริปต์นี้รัน 3 ชั้น — **อย่าประกาศว่าเสร็จถ้ายังไม่ผ่านทั้งสามชั้น**

1. `scripts/e2e.py` — HTTP e2e: 38 เส้นทาง, เนื้อหาไทยในบันเดิล, ไฟล์โลโก้, cache/compression, SPA fallback
2. `scripts/browser-check.mjs` — **เบราว์เซอร์จริง (Playwright)**: ยืนยันว่าแอป mount จริง (`#root` มีลูก), ไม่มี page error,
   ธีมเป็นโหมดสว่างทุกโปรไฟล์ (รวมเครื่องที่ระบบตั้งโหมดมืด/ที่เคยจำค่า dark), และจำลองเบราว์เซอร์ในแอปที่บล็อก `localStorage`
3. `scripts/check-logo-ratio.mjs` — วัดสัดส่วนโลโก้ header/footer เทียบขนาดไฟล์จริง (กันภาพถูกยืด)

> บทเรียนที่ทำให้สคริปต์ชุดนี้มีอยู่: HTTP 200 ไม่ได้แปลว่าเว็บแสดงผลได้ — เคยมีบั๊กที่ทำให้หน้าขาวทุกเบราว์เซอร์
> แต่ `curl` ยังได้ 200 ครบ

## เปลี่ยนแบรนด์ (ทำได้ในไฟล์เดียว)

ค่าสี/ฟอนต์/มุมโค้ง/เงา/พื้นโทนสีทั้งหมดอยู่ใน **`src/styles/tokens.css`** — แก้ที่นั่นแล้วทั้งระบบเปลี่ยนตาม
รวมถึงโหมดมืดที่ประกาศเป็นชุดค่าของตัวเองในไฟล์เดียวกัน

### โลโก้ใน `public/brand/`

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `mobyconnex-horizontal.png` | พื้นสว่าง (ค่าเริ่มต้น) |
| `mobyconnex-horizontal-dark.png` | พื้นเข้ม (คำว่า CONNEX พลิกเป็นสีอ่อน) |
| `mobyconnex-footer.png` | ฝังลงพื้นกรมท่าโดยตรง (ทึบ) — พื้นเรียบ 100% |
| `mobyconnex-mark.png` | มาร์คเดี่ยว (favicon) |
| `mobyconnex-on-navy.png`, `mobyconnex-on-green.png` | พื้นกรมท่า / พื้นเขียว (สไลด์ โปรโมชัน) |
| `mobyconnex-vertical.png` | แนวตั้ง เมื่อพื้นที่แคบ |

**กฎสำคัญ:** ไฟล์โลโก้ทำจากภาพ JPEG ต้นฉบับ — ต้องสร้างมาสก์ตัวอักษรจริง (ไม่ใช่ตัดพื้นหลังขาวตามความสว่าง)
และ **ตรวจด้วยตัวเลข** ว่าพิกเซลนอกมาสก์ต่างจากพื้นไม่เกิน 2 ระดับ มิฉะนั้นจะเกิดคราบ/กล่องสีอ่อนบนพื้นเข้ม
นอกจากนี้ รูปที่วางในคอลัมน์ flex ต้องมี `self-start` ไม่งั้นจะถูกยืดจนสัดส่วนเพี้ยน

## โครงสร้างโปรเจกต์

```
src/
  components/
    ui/        คอมโพเนนต์ที่ใช้งานจริง (ปุ่ม ฟอร์ม ตาราง ฯลฯ)
    docs/      ตัวช่วยหน้าเอกสาร (เดโม, บล็อกโค้ดคัดลอก, ตารางพร็อพ)
    site/      โครงเว็บ (header, sidebar, ค้นหา, ปุ่มธีม)
  content/     เนื้อหาเอกสารภาษาไทยทั้งหมด + registry ที่ผูกเมนู/ค้นหา/เส้นทาง
  pages/       หน้าเว็บ (landing ลูกค้า, showcase, หน้าแรกดีไซน์, หน้าเอกสาร)
  styles/      tokens.css (แบรนด์) + global.css
scripts/       e2e.py · browser-check.mjs · check-logo-ratio.mjs · verify-all.sh
```

## การเพิ่มหน้าอกสารใหม่

1. เพิ่มคอมโพเนนต์เนื้อหาใน `src/content/*.tsx`
2. เพิ่มรายการใน `src/content/registry.tsx` (1 บรรทัด) — sidebar, ⌘K และ router อ่านจากที่เดียวนี้
3. รัน `bash scripts/verify-all.sh` ก่อน commit
